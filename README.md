# University GPA Calculator

A lightweight command-line Python utility built for university students to quickly compute semester Grade Point Averages (GPA) on a standard 4.0 scale.

## Features
- Supports standard letter grades (`A` through `F` including `+` and `-` modifiers).
- Validates credit hours and grade inputs automatically.
- Zero external dependencies (runs on standard Python 3).

## Usage
```bash
python gpa_calculator.py
